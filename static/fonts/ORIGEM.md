# Fonte Inter

`InterVariable.woff2` é o arquivo oficial, sem modificações, da distribuição
**Inter v4.1**, do projeto [rsms/inter](https://github.com/rsms/inter).
O arquivo variável cobre os pesos 100 a 900 e inclui os caracteres do português.

- Versão fixa: [`v4.1`](https://github.com/rsms/inter/tree/v4.1).
- Commit da versão: `e3a3d4c57d5ecc01453a575621882a384c1995a3`.
- [Binário original](https://raw.githubusercontent.com/rsms/inter/v4.1/docs/font-files/InterVariable.woff2).
- Licença: **SIL Open Font License 1.1**, reproduzida integralmente em `OFL.txt`
  a partir do [`LICENSE.txt` oficial](https://raw.githubusercontent.com/rsms/inter/v4.1/LICENSE.txt).
- Tamanho: 352.240 bytes.
- SHA-256: `693b77d4f32ee9b8bfc995589b5fad5e99adf2832738661f5402f9978429a8e3`.

A aplicação serve este arquivo em `/static/fonts/InterVariable.woff2`.
O navegador obtém a fonte do próprio servidor local, sem acessar serviços
externos de fontes. Os estilos mantêm as fontes do sistema como alternativa.
